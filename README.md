# 日程 · DayDesk

一个在 Windows 上使用的本地每日工作台：看今天要做什么、每条主线走到哪一步，以及重要日期前还有什么待处理。

## 下载

前往 [最新版本下载页](https://github.com/Veture1/DayDesk--/releases/latest)，在 Assets 中下载 `DayDesk-Windows.zip`，解压后双击 `DayDesk.exe`。普通使用者无需下载源码或安装开发环境。

## 开始使用

1. 把整个应用文件夹解压到有写入权限的位置，例如「文档」。
2. 双击 `DayDesk.exe`。首次打开是屏幕右侧的窄窗口；可以自行调整大小，也可以在顶部「⋯」菜单切换到「⅓ 屏」。
3. 从今天的待办开始记录。首次使用的主线区域为空，点击「管理」添加自己的计划。数据保存在应用旁的 `data` 文件夹，修改后自动保存。

应用面向 Windows 10 / 11，使用系统自带的 .NET Framework，不需要账号或联网；已在当前电脑编译并运行验证。请保持整个应用文件夹完整，备份或换电脑时一并复制 `data` 文件夹。

## 四个核心区域

- **每日待办**：按日期查看任务，添加、修改、完成或移到明天。待办可以关联主线中的具体任务。
- **主线**：按自己的计划设置名称与路线，主页显示「求职 → 简历优化」这样的当前节点。点击主线，查看完整路线、已完成节点和节点下的任务。
- **关键日程**：点击顶部「编辑与清单」，添加单次日期、每周组会或每月会议；名称、日期、重复方式和时间都可编辑。
- **便利贴**：在窗口下半部分记录当日想法，自动保存。重要的便利贴可以固定到每天，收工时一键收进笔记本。拖动上下区域之间的分隔线可以调整比例。

主线不使用手动百分比。完成一个具体任务会更新对应记录，不会自动推进节点。想切换阶段时，单独点击节点的「设为当前」；确认整个阶段结束后，再点击「完成整个节点」。

可以同时保存多个关键日程，首页优先显示最近的一项。每周、每月日程在本次时间过去后自动转到下一次；每月 29–31 日遇到没有该日期的月份，使用该月最后一天。准备清单为这些日程共用。日程显示与倒计时会自动刷新，当前版本没有会议通知或系统闹钟。

## 设置自己的主线

点击主线区域的「管理」，即可添加、改名、调整顺序或删除主线。添加时可以一次填写路线节点，每行一个；也可以先建主线，之后再补节点。主线名称和数量都由自己决定。

打开一条主线后，可以添加、改名、排序或删除路线节点，以及添加、改名或删除节点内的具体任务。

删除主线或节点时，关联的每日待办会保留并解除关联。删除具体任务只解除与该任务的关联，保留待办的主线与节点信息。删除当前节点不会自动替你选择下一节点，需要时点击其他节点的「设为当前」。

## 侧边窗口与每日收工

点击「收起」或最小化，窗口会变成屏幕边缘的小标签；点击或把鼠标移到标签上即可展开。离开应用一小会儿后会自动收起。需要一直查看时，在「⋯」菜单开启「保持展开」，窗口也会置顶；同一菜单可以切换窄窗和三分之一屏宽度。

「当日想法」区域的「收工存档」会把当前所选日期的便利贴收进笔记本。未固定的便利贴收录后从工作台移走，固定的便利贴仍会留在工作台。点击「笔记本」可按日期回看、搜索、复制和编辑长想法。相同便利贴的相同内容不会重复收录；修改后再归档会保存新记录，保留之前的版本。笔记本里的编辑不会反向修改工作台便利贴，也不会被重复归档覆盖。

开启「趣味收工提醒」时，如果所选日期还有未完成待办，点击「收工存档」会出现一次可关闭的闪电吐槽和短暂窗口晃动，每天最多一次，没有声音。即使没有便利贴，也可以点击「收工存档」；在「⋯」菜单取消「趣味收工提醒」即可关闭。它不会在午夜或会议时间自动弹出。

弹窗标题是「电击你」，提示为「怎么又没do完？快点给我大do特do，狠狠do！」。当天已经提醒过，再点「收工存档」不会重复弹出。如果系统关闭了窗口动画，仍会显示弹窗，但不会晃动。

## 让 AI 帮你更新

点击顶部「AI 更新」，复制当前上下文给 AI，让 AI 按 [AI 更新指南](AI更新指南.md) 生成 JSON。将 JSON 粘贴回应用，检查预览后应用。

也可以让能读写本地文件的 AI 把更新文件放到 `data/inbox`。底部会出现「AI 待审更新」；点击后选择文件、检查预览，再应用。成功处理的文件会移到 `data/processed`。无效文件保留在待审列表，不影响选择其他文件。

例如可以对 Codex 说：

> 阅读这份 AI 更新指南和应用的当前数据。今天做完跳跃游戏，复习了 HTTP 缓存，明天继续登录模块。请生成更新文件放进 data/inbox，并告诉我改了哪些内容。

请把应用实际所在路径一并告诉 AI。未完成或不确定的事项应保留为笔记，避免 AI 将它们猜成完成记录。

附带的 `sample-update.json` 可以用来试用，只会添加一张示例便利贴。每份更新有唯一 ID，重复导入不会重复记账。在关闭应用或进行后续数据修改前，可以撤销刚应用的 AI 更新。

## 数据与备份

所有记录均保存在本地：`data/state.json` 是当前数据，`data/state.backup.json` 保存上一次写入前的数据。应用启动时遇到损坏的主文件，会尝试从有效备份恢复并保留损坏文件。

需要移动应用时先关闭窗口，再移动整个应用文件夹；不要只移动可执行文件。编辑数据文件前先备份整个 `data` 文件夹。底部没有待审更新时，点击「数据文件夹」即可打开保存位置。

应用内没有聊天模型，也不会自动读取 GitHub、浏览器、求职网站或 LeetCode 账号；AI 更新来自你提供的文字与应用上下文。

## 升级与分享

升级前关闭正在运行的应用，备份 `data` 文件夹，再用新版 `DayDesk.exe` 替换旧文件；保留原有 `data` 文件夹。旧版已保存的四条主线或你已有的其他主线都会保留，不会被空白配置覆盖。原来的离境日期与检查清单也会保留，事件名称默认显示为「离境」，可以自行改名。

分享给朋友时，发送不含 `data` 文件夹的发行压缩包。朋友首次启动会生成独立数据，从空白主线和准备清单开始设置，关键日期也不会带上你的个人安排。不要把自己的 `data` 文件夹放进分享包。

## 源码与验证

`source` 文件夹包含完整 C# 源码，界面使用 Windows 原生 WPF。运行 `source/build.ps1` 会在 `source/bin` 生成程序，无需 NuGet 或 npm；`source/test.ps1` 运行核心测试，`source/test-ui.ps1` 在临时测试目录检查控件行为并生成界面预览。程序运行时请先关闭它，再覆盖对应可执行文件。

本版通过 20 项核心测试与 9 项独立进程内的界面检查，覆盖自定义主线、周/月重复边界、旧数据兼容、笔记快照、收工提醒、侧边收纳及还原。桌面操作工具此次不可用，界面检查通过应用控件和实际 WPF 渲染完成。
